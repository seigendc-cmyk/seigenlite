RPN Setup GuideStep-by-step installation and configuration
RPN USE

Tick each step as you finish it

Prepare before the visit MUST

  • Your field force number (RPN-…) and your 6-digit RPN PIN; a charged phone with data.
  • Ask the owner to have: their own phone, the device(s) for the till, and a product list (an Excel sheet helps).
  • The shop device must be online for setup.

Install the app on the main till

  • Open the seiGEN Commerce Lite link supplied by seiGEN on the shop device.
  • Install it (phone: Add to Home screen / Install; PC: install option or desktop app), then open it from the new icon.

Setup: Welcome → Contact & branding → RPN → Confirm MUST

  • Welcome: shop name, branch name and Main / Remote Branch, plus the Activation secret phrase that you (the RPN) or Digital Commerce give the owner. Type it exactly, copy it onto page 5 and read it back to the owner.
  • Contact & branding: contact details and the owner's own phone number exactly as on page 1.
  • RPN: type your field force number and your 6-digit RPN PIN. The link is locked afterwards.
  • Confirm: finishing setup starts the free trial (with the RPN fields filled). One trial per phone number: never help a shop get around this. A paid licence is activated later.

Admin passcode (in Settings, after setup) MUST

  • In Settings, the owner chooses the Admin passcode (this till). Record it only on the Vendor Private Recovery Sheet (page 5).
  • Never photograph these, never send them by WhatsApp or SMS, never keep a copy.

Create the first Owner

  • In Settings, after setup, create the Owner on the main till. The owner sets their own PIN (never written down).
  • Explain single operator mode (one person, no PIN sign-in) versus PIN sign-in (each person signs in; the role decides what they see). Set the one the owner wants.

Staff and roles

  • Sign in to manage staff, then add each person from section E with their role: Owner, Admin, Manager, Stores, Cashier or Guest.
  • Each person types their own PIN. If roles don't show, tap Refresh while online.
  • The role decides everything, and seiGEN checks it too.

Products and stock

  • Add products by hand or with Products → ⋮ → Import from Excel; set categories, prices (retail and wholesale) and cost.
  • Enter opening stock; fill in Shelf / Location (e.g. "A3") if the shop wants cycle counts.

Branches, tills and Office seats IF NEEDED

  • Remote branch tills: install the app there and join with the join code from the main till.
  • Office seats: send an invite (code + link), single use, valid 24 hours, for a named person; approve the device. $3 per 30 days.

Receipts and settings

  • Set the receipt message and logo, the customer defaults (Cash Sale and Wholesale are built in), and credit limits if the shop sells on credit.

Test sale and End of Day MUST

  • Make one test sale with the owner, print or share the receipt, then do an End of Day so they see the cash-up.

Backups and data safety MUST

  • Show how to make a backup and where to keep it. Never clear browsing or site data on a shop device: it deletes the shop's data.

iTred Marketplace OPTIONAL

  • Choose products → Add to Marketing → build the market pack (photos) → Send to seiGEN.
  • 1 token = 1 day = USD 1 per pack; seiGEN reviews it before it goes live; orders arrive in Orders Fulfillment. Share the iTred link on WhatsApp.
