# iTred fonts (A14, owner 27 Oct 2026)

Served from iTred's own address (build.js copies them into dist-itred/), so the
site never loads Google Fonts at runtime. The same files Google Fonts served on
27 Oct 2026 (latin and latin-ext subsets, variable weight 400-700):

- `fraunces-latin.woff2`, `fraunces-latin-ext.woff2`: Fraunces, by Undercase Type
- `inter-latin.woff2`, `inter-latin-ext.woff2`: Inter, by Rasmus Andersson

Both are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org),
which allows bundling and serving them with the site.
